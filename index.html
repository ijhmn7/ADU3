ABOUT THE ARCHIVE

Built for evidence, context and citation.

Every item has a stable catalogue ID, title, date, description, place, people, subject terms, collection, source reference, rights statement and links to digital files where available.

The archive is deliberately transparent: metadata lives in the same GitHub repository as the website, so changes are versioned and the catalogue can be backed up, forked or preserved independently.
